# Security

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues.

Use one of these private reporting channels:

1. Submit a report through the
   [NVIDIA Vulnerability Disclosure Program](https://www.nvidia.com/en-us/security/report-vulnerability/).
2. Email NVIDIA PSIRT at `psirt@nvidia.com`. Encrypt sensitive reports with
   the NVIDIA PSIRT PGP key.
3. If private vulnerability reporting is enabled for this repository, use
   **Security** > **Report a vulnerability** on GitHub.

Include the affected portion of the specification or implementation, a clear
description of the impact, and enough detail to reproduce or evaluate the
issue.

NVIDIA PSIRT coordinates triage and disclosure according to the
[NVIDIA PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/).
